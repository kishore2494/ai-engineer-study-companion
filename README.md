# AI Engineer Study Companion

All 11 volumes — a single-page interactive study guide: 308 topics from Python to production LLM systems,
plus appendices (system architectures, scenario drills, the frontier mind, quantum & frontier, market &
positioning, AI testing) and a 175-term glossary.

- **Narrated video for every topic** (388 videos: 369 sections + 19 glossary parts). Click "Watch video" on any
  topic; glossary terms have a ▶ that opens the video at that term. Videos live in `videos/` with captions (VTT).
- **Accuracy:** the whole site was technically audited on 2026-11-01 (163 fixes to facts, code and numbers).

**Live:** https://kishore2494.github.io/ai-engineer-study-companion/
